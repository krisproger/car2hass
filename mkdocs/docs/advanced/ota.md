# OTA-обновления

Часть конфигурации приложения обновляется «по воздуху» с сайта проекта — без переустановки APK.

## Что обновляется

| Пакет | Что внутри | Файл на сайте |
|-------|-----------|----------------|
| **Пресеты дашборда** | набор плиток-пресетов: сенсоры, команды, иконки, переводы | `dashboard_presets.json` |
| **Реестр сенсор↔команда** | соответствие сигналов и команд: верификация команд, связь сенсоров и элементов управления | `sensor_command_map.json` |

## Как это работает

1. Приложение раз в 6 часов запрашивает у сайта мета-файл (`*.meta.json`) с номером версии пакета.
2. Если версия на сайте новее — скачивает полный JSON и сохраняет в данные приложения.
3. Новый пакет применяется сразу: пресеты перестраивают плитки, реестр — связи команд и сенсоров.
4. Если скачанный пакет битый или сеть недоступна — используется встроенный в APK (fallback).

## Принудительное обновление

**Настройки → Сервис → Обновить пресеты** — проверка немедленно, без ожидания 6-часового интервала. Рядом с кнопкой показана текущая версия пакета. После обновления плитки дашборда перестраиваются автоматически; результат показывается toast-сообщением (обновлено / уже последняя / ошибка).

## Версии пакетов

Версия пакета отображается в настройках. Текущая версия пресетов — v4 (порт зарядки показывает подключение, режим охраны и детские замки — пресеты с кнопками-действиями, удалён дубль «Закрыть окна»). Реестр команд — v4.

!!! note "Счётчик скачиваний"
    Сайт ведёт анонимный счётчик обращений к файлам обновлений — это помогает понимать, сколько установок активно. Передаётся только факт скачивания, без данных автомобиля.
