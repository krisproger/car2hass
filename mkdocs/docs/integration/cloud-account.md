# Личный кабинет и облачная синхронизация

Помимо отправки данных в Home Assistant приложение Car2Hass может синхронизировать телеметрию с **облаком mytechnic.ru** — данные будут доступны в личном кабинете через веб-интерфейс. Home Assistant для этого не нужен, а сама синхронизация опциональна и не влияет на передачу в HA.

## Вход в личный кабинет

Личный кабинет — [mytechnic.ru/account](https://mytechnic.ru/account/). Вход **без пароля**:

1. Укажите **email**.
2. Введите **код TOTP** из приложения-аутентификатора (Google Authenticator, Aegis и др.).

При первой регистрации создаётся секрет TOTP: отсканируйте QR-код в приложении-аутентификаторе и введите полученный код для подтверждения.

## Облачная синхронизация в приложении

Синхронизация включается в приложении: **Настройки → Облачная синхронизация**. После входа (email + TOTP) приложение отправляет телеметрию батчами и автоматически обновляет токен доступа.

!!! note "Облако и Home Assistant — независимы"
    Облачная синхронизация и отправка в HA — два отдельных канала. Облако можно включить, выключить или не использовать вовсе — на работу интеграции это не влияет.

## Разделы кабинета

Слева в кабинете — навигация по разделам:

| Раздел | Что внутри |
|--------|------------|
| **Дашборд** | сводка по аккаунту: активность, статус подключённых приложений, последние события |
| **Приложения** | подключённые приложения и хранилища (Car2Hass-телеметрия, файлы настроек) |
| **Профиль** | имя, телефон, аватар и настройки отображения дашборда |
| **Способы входа** | привязка внешних сервисов (OAuth) к аккаунту |
| **OAuth-клиенты** | создание, редактирование и удаление OAuth-клиентов для своих приложений |

## Трек автомобиля

Раздел приложения Car2Hass (`/account/car2hass`) показывает GPS-трек каждого автомобиля на карте (OpenStreetMap):

- **Фильтр по дате** — поля «С» и «По» ограничивают период трека.
- **Фильтр точек** — число точек на треке (500 / 1000 / 2000 / 4000 или «Максимум за период»).
- При большом объёме трек **прореживается на сервере** — первая и последняя точки сохраняются.

У каждого автомобиля видны время последнего обновления, число точек и карта; список последних сенсоров раскрывается в «Деталях».

## Хранилище файлов настроек

Кроме телеметрии у аккаунта есть хранилище **файлов настроек** (`filesettings`): приложение может сохранять туда файлы конфигураций и забирать их при подключении к аккаунту.

- Список файлов: имя, размер, дата обновления.
- Операции: **скачать**, **обновить** существующий или **загрузить** новый файл.
