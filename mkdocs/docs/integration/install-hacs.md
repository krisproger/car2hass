# Установка интеграции

Интеграцию **CARTelemetry** можно установить двумя способами — через **HACS** (обновления
автоматически) или **вручную** (без HACS).

## Установка через HACS

1. Установите [HACS](https://hacs.xyz/) в Home Assistant (если ещё нет).
2. **HACS → меню ⋮ (вверху справа) → Custom repositories**.
3. Вставьте URL публичного репозитория:
   `https://github.com/krisproger/car2hass`
   и выберите категорию **Integration** → **Add**.
4. **HACS → Интеграции** → найдите **CARTelemetry — Vehicle Telemetry** → **Download**.
5. **Перезагрузите Home Assistant** (Настройки → Система → Перезагрузка), чтобы HA
   увидел новую интеграцию.
6. Добавьте интеграцию: **Настройки → Устройства и службы → Добавить интеграцию →
   CARTelemetry** → введите имя автомобиля (латиницей, без пробелов).

Обновления: HACS автоматически показывает новую версию (интеграция публикует релизы с
тегом `vX.Y.Z`). Для обновления — **HACS → Интеграции → ⋮ → Обновить** и перезагрузка.

### Если интеграция не видна в HACS
- Убедитесь, что репозиторий добавлен как **Integration** (не Frontend).
- После «Add» нажмите **Reload** в HACS.
- Проверьте: в репозитории есть `custom_components/cartelemetry/` в корне и `hacs.json`.

## Установка вручную (без HACS)

1. Скачайте архив последней версии:
   - с сайта: <https://mytechnic.ru/cartelemetry/download.php?file=integration>
     (файл `cartelemetry-vX.Y.Z.zip`), или
   - из GitHub **Releases** репозитория (вкладка Releases → последний релиз → asset).
2. Распакуйте архив. Внутри папка `cartelemetry/`.
3. Скопируйте её в каталог конфигурации HA:
   ```
   <каталог конфигурации HA>/custom_components/cartelemetry/
   ```
   (папку `custom_components` создайте, если её нет).
4. **Перезагрузите Home Assistant**.
5. Добавьте интеграцию: **Настройки → Устройства и службы → Добавить интеграцию →
   CARTelemetry** → имя автомобиля.

### Карточка автомобиля (дашборд)
Интеграция при старте сама копирует карточку и картинку в
`www/community/cartelemetry-card/` и регистрирует ресурс
`/local/community/cartelemetry-card/car-card.js`. Если карточка не появилась —
добавьте ресурс вручную (Настройки → Панели управления → ⋮ → Ресурсы →
`JavaScript Module` → `/local/community/cartelemetry-card/car-card.js`) и обновите
страницу (Ctrl+F5). Подробнее — [Карточка автомобиля](dashboard-card.md).

### Обновление вручную
Замените папку `custom_components/cartelemetry/` на новую версию и перезагрузите HA.
Данные (сущности, устройства) сохранятся — папка содержит только код интеграции.

### Проверка установки
После добавления интеграции в разделе **Устройства и службы → CARTelemetry** появятся
устройство автомобиля, сущности `sensor.<car>_*` и трекер. Приложение Car2Hass на ГУ
(или на телефоне с OBD-адаптером) начнёт передавать телеметрию, как только укажет
то же имя автомобиля.

## Требования
- Home Assistant **2024.1+**.
- Один из источников данных: приложение Car2Hass (BYD/Voyah ГУ), либо любое приложение
  по [открытому API-контракту](api-spec.md) (например, на телефоне с OBD2-BT адаптером).
