# Фоновый режим (ACC off)

По умолчанию Android на головном устройстве усыпляет приложения после выключения авто. Фоновый режим позволяет DiPlus-to-hass продолжать работу: собирать телеметрию, выполнять команды из HA и правила.

## Включение

1. **Настройки → Работа при выключенном авто** — включите.
2. При первом включении приложение попросит разрешение ADB-подключения — подтвердите на экране ГУ.
3. Приложение попытается автоматически выполнить системные настройки через ADB (localhost):
    - выдать себе `WRITE_SECURE_SETTINGS` и `DEVICE_POWER`;
    - включить `allow_online_while_car_off`;
    - добавить себя в белый список Doze.
4. Если прошивка блокирует автоматическое выполнение, приложение покажет точные ADB-команды для ручного запуска с ПК:

    ```bash
    adb connect <IP_ГУ>:5555
    adb shell pm grant com.diplustohass android.permission.WRITE_SECURE_SETTINGS
    adb shell pm grant com.diplustohass android.permission.DEVICE_POWER
    adb shell settings put global allow_online_while_car_off 1
    adb shell dumpsys deviceidle whitelist +com.diplustohass
    ```

5. Адрес ADB-подключения меняется в настройках (**ADB host/port**, по умолчанию `127.0.0.1:5555`).

## Автозапуск

Для надёжной фоновой работы дополнительно:

1. Пункт меню автозапуска в приложении открывает системное окно BYD **AppStartManagement** — разрешите автозапуск DiPlus-to-hass.
2. Исключите приложение из оптимизации батареи в системных настройках.

## Логирование

В фоновом режиме лог пишется в файл сразу после старта приложения (а не только в память) и сбрасывается на диск при остановке сервиса — это нужно для анализа работы на выключенном авто. Файлы — в папке `logs` приложения, экспорт через меню настроек.

## Ограничения

- Режим зависит от прошивки DiLink: на части прошивок система всё равно выгружает приложение через некоторое время после ACC off.
- Режим «сентри» автомобиля и команды на заглушенном авто зависят от самого автомобиля и DiPlus — приложение лишь транспортирует команды.
- Следите за аккумулятором: длительная работа ГУ на стоянке потребляет энергию.
