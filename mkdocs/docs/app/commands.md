# Команды

Вкладка **Команды** — выполнение любой команды из каталога вручную и просмотр журнала выполнения.

## Как выполнить команду

1. Выберите категорию и команду из списка.
2. Если команда требует параметр, появится поле ввода:
    - **число** (температура 16–30 °C, SOC 0–100, громкость 0–100 и т.д.) — с подсказкой диапазона;
    - **диапазон** (окна, люк, шторка 0–100 %) — слайдер/поле процентов;
    - **перечисление** (режим движения, обдув, рециркуляция) — список локализованных вариантов;
    - **строка** (расписание зарядки) — свободный текст в формате команды.
3. Нажмите **Выполнить**. Результат и верификация появятся в журнале внизу экрана; журнал прокручивается внутри своей области и не уводит весь экран вниз.

## Категории команд

| Категория | Примеры |
|-----------|---------|
| Климат | климат вкл/выкл/авто, температура, вентилятор, направление обдува, рециркуляция, подогрев/обдув сидений, подогрев руля, зеркал, обдув лобового |
| Окна | каждое окно и люк/шторка в процентах, закрыть всё, проветривание |
| Двери | центральный замок, багажник, детские замки |
| Свет | аварийка, поворотники, противотуманки, ДХО, свет в салоне, подсветка, авто-дальний |
| Режимы | HEV/EV/Force EV, ECO/SPORT/NORMAL/SNOW, умный/принудительный заряд, рекуперация, усилители руля и тормоза, активный тормоз |
| Зарядка | целевой SOC, расписание зарядки |
| Громкость | медиа, навигация, внешний динамик, ± громкости |
| Охрана | режимы «сентри» (при выключенном двигателе, таймлапс), панорамный регистратор |
| Комфорт | высота фар, режимы «дальняя поездка/город/сон», гашение экрана |
| Система | ADB вкл/выкл, тема ГУ, HUD |

## Проверка выполнения (верификация)

После отправки команда сверяется с реальным состоянием автомобиля через [связанный сенсор](../advanced/ota.md): например, «окно водителя 15 %» проверяется по датчику `window_fl`. В журнале видно `ожидалось / фактически`.

- Команды вкл/выкл проверяются по совпадению состояния.
- Числовые — с допуском (окна ±2 %, температура ±1 °C, громкость ±5).
- Если у команды нет связанного сенсора, в журнале пишется «нет связанного сенсора».

!!! note "Медленные механизмы"
    Окна и люк движутся медленно — верификация для них ждёт дольше (до ~7 секунд). Если стекло не дошло до цели, в журнале будет «несоответствие состояния» с фактическим значением; повторный запуск команды обычно доводит её до конца.

Журнал показывает каждую команду: источник (UI/HA), китайскую команду для DiPlus, ответ DiPlus, результат верификации. Экспорт лога — через меню (передать/сохранить в Загрузки).

## Быстрые команды на дашборде

Любую команду можно вынести плиткой на [дашборд](dashboard.md) — в режиме редактирования выберите «Команды» в списке добавления. Для параметрических команд параметр задаётся при настройке плитки.
