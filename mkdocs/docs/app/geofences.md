# Геозоны

Геозоны — области на карте, при входе/выходе из которых меняется виртуальный датчик. Датчики можно использовать в [правилах](rules.md), а в Home Assistant они приходят как бинарные сенсоры.

## Создание зоны

1. Меню → **Геозоны** → кнопка **+**.
2. Введите название зоны (например, «Дом», «Работа»).
3. На карте (OpenStreetMap) установите центр зоны — перетаскиванием маркера.
4. Задайте радиус слайдером (от 10 до 500 м, по умолчанию 100 м) — круг на карте показывает границу.
5. Сохраните.

Для создания зоны нужны разрешения на геолокацию (приложение запрашивает их при первом запуске) и текущие координаты автомобиля.

## Как это работает

- Каждые несколько секунд приложение сравнивает текущую позицию с центрами всех зон (формула гаверсинуса).
- Зона создаёт виртуальный сенсор `geo_<id>` со значением `inside` / `outside`.
- Этот сенсор доступен в условиях правил наравне с обычными сигналами: например, «`geo_a1b2c3d4` = inside → включить свет в салоне».
- При переходе **outside → inside** фиксируется время последнего посещения — оно показывается в списке зон («дом (100м) — последний визит: сегодня 08:12»).

## Геозоны в Home Assistant

Каждая зона автоматически появляется в HA как бинарный сенсор:

```
binary_sensor.<имя_авто>_geofence_<название_зоны>
```

- `on` — автомобиль внутри зоны, `off` — снаружи.
- Класс устройства — presence.
- Имя сущности берётся из названия зоны (при переименовании зоны перезагрузите интеграцию).

## Экспорт

Зоны входят в [экспорт конфигурации](settings.md#экспорт-импорт) вместе с правилами и настройками — перенос на другое ГУ одним файлом.

!!! note "Точность"
    Геопозиция берётся из данных автомобиля (через DiPlus). В гаражах и тоннелях координаты могут «замерзать» — зона сработает с задержкой до восстановления сигнала GPS.
