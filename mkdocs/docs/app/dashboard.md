# Дашборд

Дашборд — первый экран приложения: сетка настраиваемых плиток с ключевыми данными и управлением.

## Плитки

Плитка бывает трёх типов:

- **Пресет** — готовая карточка из пакета пресетов (климат, двери, окна, батарея и т.д.). Пресеты обновляются [по воздуху](../advanced/ota.md), их набор не зависит от версии APK.
- **Сенсор** — одиночный сигнал телеметрии (например, конкретное колесо или температура).
- **Команда** — кнопка действия (с параметром или без).

По умолчанию на новой установке стоят плитки: скорость, батарея, запас хода, порт зарядки, температура салона и улицы, двери, давление в шинах, свет, статус HA, климат, громкость, аварийка, окна.

### Плитки с зонами ➖/➕

Громкость, вентилятор и температура — плитки с двумя зонами действия. Трёхстрочная разметка: иконка по центру, строка `➖ значение ➕`, название сенсора.

- **Левая четверть** — уменьшить (`volume_down`, `ac_fan_down`, `ac_temp_down`).
- **Правая четверть** — увеличить (`volume_up`, `ac_fan_up`, `ac_temp_up`).
- **Центр** — основное действие плитки (для громкости — установка уровня, для климата — вкл/выкл).

### Иконки

Иконки пресетов — PNG-файлы (Material Design Icons), встроенные в приложение. Если какая-то иконка не нравится, положите свою `icons/<имя>.png` в папку данных приложения — она будет использоваться вместо встроенной. Если PNG не найден, показывается эмодзи-запасной вариант.

## Режим редактирования

**Вход:** долгий тап по любой плитке.

В режиме редактирования:

- у каждой плитки появляется значок удаления;
- **FAB «+»** (справа внизу) — добавить плитку: выбор из списка пресетов, сенсоров и команд, сгруппированных по категориям (Климат, Окна, Свет и т.д.); уже добавленные элементы в списке не показываются;
- **FAB «✓»** (слева внизу) — завершить настройку.

**Автовыход:** если 15 секунд нет действий, изменения сохраняются и режим завершается. Пока открыт любой диалог (выбор плитки, настройка параметров) — таймер стоит на паузе.

### Плитка с командой и параметром

При добавлении команды с параметром (например, «открыть окно водителя на N %») откроется диалог настройки параметра: значение по умолчанию для этой плитки. Для команд-перечислений (режим движения, обдув) параметр выбирается из списка.

### Пресеты с действиями и параметрами

У пресетов с несколькими действиями (окна, свет и т.д.) тап по плитке открывает **сетку кнопок** (2 колонки при трёх и более действиях, 1 колонка при 1–2) вместо списка. У пресета «Окна» кнопки: **Закрыть** (все), **Открыть** (4 дверных стекла на 100 %; люк и шторка не трогаются), **Проветрить**, **Свои значения** (если сохранены свои проценты).

Пресеты с параметрами (окна, климат) **запоминают введённые значения**. В режиме редактирования тап по плитке открывает диалог параметров с тремя кнопками:

- **Сохранить** — только запомнить значения (команды не выполняются);
- **Сохранить и применить** — запомнить и сразу выполнить;
- **Отмена**.

Сохранённые значения доступны в обычном режиме кнопкой **Свои значения**: для окон — в диалоге действий, для климата (toggle) — в диалоге **Вкл / Выкл / Свои значения** (появляется, только если значения сохранены; иначе тап работает как обычный переключатель).

## Верхняя статусная строка

Над дашбордом — строка состояния: VVIN, версия ПО автомобиля, GPS-статус, время последнего обновления. **Тап по VVIN или версии ПО копирует значение в буфер обмена.**

## Таблица телеметрии

Под дашбордом — полная таблица сигналов. Галочка у сигнала = передавать в HA. Галочка в шапке — выбрать/снять все. Клик по заголовку столбца — сортировка. Сигналы, не поддерживаемые автомобилем, показываются в списке без галочек: они продолжают опрашиваться, но в HA не отправляются.

Выбор запоминается в конфигурации и входит в [экспорт/импорт](settings.md#экспорт-импорт).
