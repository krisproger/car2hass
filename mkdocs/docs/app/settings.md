# Настройки

Экран настроек приложения (меню → **Настройки**). Сверху — левая колонка разделов: **Авто / Сервисы и источники данных / Умный дом / Геозоны / Опции / О программе**. Клик по пункту показывает соответствующую карточку справа («Геозоны» и «О программе» открываются отдельными окнами). Все параметры сохраняются автоматически при изменении — отдельной кнопки «Сохранить» нет.

## Авто {#авто}

Карточка профиля автомобиля — базовый раздел, открывается первым.

| Параметр | Описание |
|----------|----------|
| **Производитель** | `BYD` (по умолчанию) или **«Универсальный авто с Android»**. Для универсального авто управление командами недоступно, вместо него появляется кнопка **Исследование каналов** |
| **Марка / модель** | например, `Voyah FREE`; используется в имени файла отчёта исследования |
| **Год выпуска** | год автомобиля |

### Исследование каналов (универсальный авто)

Для профиля **«Универсальный авто с Android»** в карточке появляется кнопка **Исследование каналов**. Она зондирует четыре канала получения данных (каждый с таймаутом 15 с):

- **системные свойства** — `getprop` (производитель, модель, прошивка);
- **DiPlus** — HTTP-сервер DiPlus;
- **ADB (native)** — on-device ADB `service call autoservice`;
- **экспериментальный** — пробное выполнение команд ADB.

После завершения показывается сводка по каждому каналу (`доступен` / `нет данных` / `отказ` / `таймаут`). На время зондирования открывается модальное окно с прогресс-баром, показывающим ход по каналам. Кнопка **Отправить лог** в диалоге прикладывает полный отчёт `research_<марка>_<дата>.txt` к экспортируемому логу. Для профиля BYD исследование скрыто — работают штатные каналы DiPlus → ADB → системные свойства с управлением командами.

## Сервисы и источники данных {#сервисы-и-источники-данных}

| Параметр | Описание |
|----------|----------|
| **Источник телеметрии** | `auto` (по умолчанию), `native` или `diplus`. Управляет и чтением сигналов, и каналом записи команд: `native` — прямой ADB (`service call autoservice`), `diplus` — HTTP-сервер DiPlus. В режиме `auto` приложение запоминает, какой интерфейс отвечал последним, и начинает с него. Если один канал недоступен — команда применяется через второй (взаимный фоллбэк) |
| **Сравнение native и DiPlus (debug)** | включает сравнение значений native-чтения с DiPlus в логе — для отладки |
| **ADB host / port** | адрес on-device ADB (по умолчанию `127.0.0.1:5555`) |
| **DiPlus auth** | параметр авторизации HTTP-сервера DiPlus |

## Умный дом {#умный-дом}

Подключение к Home Assistant.

| Параметр | Описание |
|----------|----------|
| **HA адрес сервера** | `host:port`, например `192.168.1.10:8123`. Если порт не указан — подставляется `8123`, а при включённом HTTPS — `443` |
| **HTTPS** | чекбокс в строке адреса — включите, если HA за reverse-proxy с TLS |
| **Токен** | Long-Lived Access Token из профиля HA. Значок `?` рядом показывает краткую инструкцию, как его создать. Хранится зашифрованным (Android Keystore) |
| **Имя автомобиля** | префикс сущностей в HA; должно точно совпадать с именем, заданным при добавлении интеграции. При первом запуске подставляется VVIN — замените на своё |
| **Отправлять в HA** | мастер-переключатель передачи телеметрии (не останавливает локальный сбор) |
| **Проверить соединение** | кнопка проверки связи с HA по текущим параметрам |

## Геозоны {#геозоны}

Пункт левой колонки **Геозоны** открывает список геозон — см. [Геозоны](geofences.md). Ранее кнопка находилась в разделе «Прочее».

## Опции {#опции}

| Параметр | Описание |
|----------|----------|
| **Автозапуск при загрузке** | старт сервиса при включении ГУ |
| **Управление авто из HA** | опрос команд из Home Assistant. По умолчанию выключено — включайте осознанно |
| **Запись лога в файл** | три режима: **Выкл** — файл не ведётся, лог только в памяти и выгружается по требованию (экспорт); **Базовый** — в файл непрерывно пишутся события, предупреждения и ошибки (без RAW-тел); **Подробный** — в файл пишется всё, включая тела RAW-ответов DiPlus и детали команд. В памяти лог ведётся **всегда в подробном виде** (буфер с ограничением по размеру), поэтому экспорт в любой момент даёт полную картину независимо от режима |
| **Очередь включена** | по умолчанию да; если выключить — при недоступности HA данные отбрасываются |
| **Макс. размер, МБ** | лимит очереди (по умолчанию 100); старые снапшоты вытесняются |
| **Макс. возраст, дней** | снапшоты старше лимита (по умолчанию 7) удаляются |
| **Работа при выключенном авто** | продолжать телеметрию и опрос команд после ACC off |
| **Автозапуск BYD** | открывает системное окно BYD **AppStartManagement** для настройки автозапуска |
| **Фоновая работа** | настройки фонового режима — см. [Фоновый режим](background.md) |
| **Применить фоновый режим** | применить текущую конфигурацию фонового режима |

> **Нативная запись (v2.3.0, бета).** Команды, для которых известны адреса autoservice, применяются напрямую через ADB — без DiPlus. Если у команды есть связанный сенсор, результат дополнительно верифицируется по состоянию авто. Журнал команд показывает использованный интерфейс (`native`/`diplus`) и число фоллбэков.

### Сервис {#сервис}

- **Язык** — русский / английский интерфейс.
- **Обновить пресеты** — принудительная проверка OTA-обновлений пакета пресетов дашборда; рядом показана текущая версия пакета. Подробнее: [OTA-обновления](../advanced/ota.md).
- **Экспорт / импорт конфигурации** — см. [Экспорт / импорт](#экспорт-импорт).
- **Экспорт лога** — через кнопку отправки лога на главном экране (вверху), а также из диалога «Исследование каналов» (кнопка **Отправить лог**). Меню: **передать** (интенты: почта, мессенджеры, облако) или **сохранить** в Загрузки с toast-подтверждением. Повторные timestamp-строки (одни и те же события в секциях «In-memory» и «Persistent File») в экспорт не дублируются.

## О программе {#о-программе}

Модальное окно с версией, ссылками на сайт и Telegram и разделами поддержки (агрегаторы, банки, криптовалюта). Открывается из раздела **О программе**, а также автоматически при первом запуске новой версии приложения (вместе с системным окном автозапуска BYD).

## Экспорт / импорт {#экспорт-импорт}

- **Экспорт конфигурации** — один JSON-файл: подключение, фильтр сигналов, правила, геозоны, параметры очереди. На Android 10+ пишется в Загрузки через MediaStore.
- **Импорт конфигурации** — восстанавливает всё из файла и перезапускает движок правил. Формат v2 принимает и файлы старого формата (v1).

!!! warning "Токен в экспорте"
    Экспорт включает токен HA — не публикуйте файл и не передавайте третьим лицам.
