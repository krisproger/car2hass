# Настройки

Экран настроек приложения (меню → **Настройки**). Все параметры сохраняются автоматически при изменении — отдельной кнопки «Сохранить» нет.

## Подключение к Home Assistant

| Параметр | Описание |
|----------|----------|
| **HA адрес сервера** | `host:port`, например `192.168.1.10:8123`. Если порт не указан — подставляется `8123`, а при включённом HTTPS — `443` |
| **HTTPS** | чекбокс в строке адреса — включите, если HA за reverse-proxy с TLS |
| **Токен** | Long-Lived Access Token из профиля HA. Значок `?` рядом показывает краткую инструкцию, как его создать. Хранится зашифрованным (Android Keystore) |
| **Имя автомобиля** | префикс сущностей в HA; должно точно совпадать с именем, заданным при добавлении интеграции. При первом запуске подставляется VVIN — замените на своё |
| **Проверить соединение** | кнопка проверки связи с HA по текущим параметрам |

## Работа приложения

| Параметр | Описание |
|----------|----------|
| **Отправлять в HA** | мастер-переключатель передачи телеметрии (не останавливает локальный сбор) |
| **Автозапуск при загрузке** | старт сервиса при включении ГУ |
| **Управление авто из HA** | опрос команд из Home Assistant. По умолчанию выключено — включайте осознанно |
| **Запись лога в файл** | три режима: **Выкл** — файл не ведётся, лог только в памяти и выгружается по требованию (экспорт); **Базовый** — в файл непрерывно пишутся события, предупреждения и ошибки (без RAW-тел); **Подробный** — в файл пишется всё, включая тела RAW-ответов DiPlus и детали команд. В памяти лог ведётся **всегда в подробном виде** (буфер с ограничением по размеру), поэтому экспорт в любой момент даёт полную картину независимо от режима |
| **Язык** | русский / английский интерфейс |

## Очередь при потере связи

Когда HA недоступен, снапшоты складываются в локальную очередь и отправляются после восстановления связи.

| Параметр | Описание |
|----------|----------|
| **Очередь включена** | по умолчанию да; если выключить — при недоступности HA данные отбрасываются |
| **Макс. размер, МБ** | лимит очереди (по умолчанию 100); старые снапшоты вытесняются |
| **Макс. возраст, дней** | снапшоты старше лимита (по умолчанию 7) удаляются |

## Фоновый режим (ACC off)

Блок настроек работы при выключенном авто и ADB-помощник — см. [Фоновый режим](background.md).

| Параметр | Описание |
|----------|----------|
| **Работа при выключенном авто** | продолжать телеметрию и опрос команд после ACC off |
| **ADB host/port** | адрес для ADB-подключения (по умолчанию `127.0.0.1:5555`) |

## Сервис

- **Обновить пресеты** — принудительная проверка OTA-обновлений пакета пресетов дашборда; рядом показана текущая версия пакета. Подробнее: [OTA-обновления](../advanced/ota.md).
- **Экспорт лога** — меню: **передать** (интенты: почта, мессенджеры, облако) или **сохранить** в Загрузки с toast-подтверждением.

## Экспорт / импорт {#экспорт-импорт}

- **Экспорт конфигурации** — один JSON-файл: подключение, фильтр сигналов, правила, геозоны, параметры очереди. На Android 10+ пишется в Загрузки через MediaStore.
- **Импорт конфигурации** — восстанавливает всё из файла и перезапускает движок правил. Формат v2 принимает и файлы старого формата (v1).

!!! warning "Токен в экспорте"
    Экспорт включает токен HA — не публикуйте файл и не передавайте третьим лицам.
