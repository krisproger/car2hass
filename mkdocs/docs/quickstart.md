# Быстрый старт

Полная установка занимает 15–20 минут. Порядок важен: сначала DiPlus, потом интеграция HA, потом наше приложение.

## Шаг 1. Установите DiPlus на головное устройство

Приложение **DiPlus** — источник данных об автомобиле. Без него DiPlus-to-hass работать не будет.

1. Скачайте [diplus.1.3.8-beta18.apk](https://teplitzky.ru/diplus2hass/download.php?file=diplus).
2. Установите на ГУ любым способом (флешка, мессенджер, ADB).
3. Запустите DiPlus и выдайте ему запрошенные разрешения.
4. Проверьте, что DiPlus видит автомобиль: на главном экране DiPlus появляются данные (скорость, SOC и т.д.).

## Шаг 2. Установите интеграцию Home Assistant

1. Скачайте [diplus2hass-v2.1.2.zip](https://teplitzky.ru/diplus2hass/download.php?file=integration) и распакуйте.
2. Скопируйте папку `custom_components/diplus2hass` в `/config/custom_components/` на сервере HA.

    ```bash
    cp -r custom_components/diplus2hass /config/custom_components/
    ```

    !!! warning "Обновление с предыдущей версии"
        Сначала **полностью удалите** старую папку `/config/custom_components/diplus2hass/`, затем копируйте новую. Перезапись поверх оставляет смешанный набор файлов и приводит к ошибкам импорта при запуске.

3. Перезапустите Home Assistant.
4. **Настройки → Устройства и службы → Добавить интеграцию** → найдите **DiPlus-to-hass — BYD Vehicle Telemetry**.
5. Введите имя автомобиля (латиницей, без пробелов — например, `BYDSongPRO`). Оно станет префиксом всех сущностей.

## Шаг 3. Создайте Long-Lived Access Token

1. В HA откройте профиль пользователя (внизу слева) → раздел **Long-Lived Access Tokens**.
2. Создайте токен с понятным именем (например, `diplus-car`) и скопируйте его — он показывается один раз.

## Шаг 4. Установите приложение DiPlus-to-hass

1. Скачайте [diplus2hass-v2.1.2.apk](https://teplitzky.ru/diplus2hass/download.php?file=app).
2. Установите на ГУ (флешка, мессенджер или `adb install -r`).
3. При первом запуске выдайте разрешения: местоположение (в т.ч. в фоне) — нужно для трекера и геозон.

## Шаг 5. Привяжите приложение к Home Assistant

В приложении откройте **Настройки**:

1. **HA адрес сервера** — адрес HA в формате `host:port`, например `192.168.1.10:8123`. Если порт не указан, подставляется `8123` (или `443` при включённом HTTPS).
2. **HTTPS** — включите, если HA работает по HTTPS (чекбокс в строке адреса).
3. **Токен** — Long-Lived Access Token из шага 3. Рядом значок `?` с подсказкой, как его получить.
4. **Имя автомобиля** — точно такое же, как в интеграции (шаг 2). При первом запуске подставляется VVIN автомобиля — замените на своё имя, совпадающее с интеграцией.
5. Нажмите **Проверить соединение** — должно появиться подтверждение.

Подробнее: [Настройки](app/settings.md).

## Шаг 6. Включите передачу данных

1. На главном экране приложения включите переключатель **Отправлять в HA**.
2. Откройте таблицу телеметрии и отметьте нужные сигналы (галочка в шапке — выбрать/снять все). Неподдерживаемые автомобилем сигналы показываются без галочек — они опрашиваются, но в HA не передаются.
3. Через несколько секунд в HA появятся сущности `sensor.<имя_авто>_*`.

## Шаг 7. Настройте автозапуск и фоновую работу

Чтобы приложение работало постоянно:

1. В меню приложения выберите пункт автозапуска — откроется системное окно BYD **AppStartManagement**; разрешите автозапуск DiPlus-to-hass.
2. В системных настройках батареи/энергосбережения исключите приложение из оптимизации.
3. Для работы при выключенном авто (ACC off) см. [Фоновый режим](app/background.md).

## Шаг 8. Управление автомобилем (опционально)

По умолчанию выключено в целях безопасности. Чтобы разрешить команды из HA:

1. **Настройки → Управление авто из HA** — включите.
2. В HA появятся переключатели, числовые поля, списки и кнопки для команд (климат, окна, замки и т.д.).
3. Подробнее: [Управление](integration/controls.md) и [Команды](app/commands.md).
